Welcome to Message Broker Service

This application demonstrates the CAP library for event-driven messaging with RabbitMQ.

Use the navigation menu above to manage:

  • Users - Register, update, and manage users (publishes UserRegisteredEvent, UserProfileUpdatedEvent)
  • Blog Posts - Create, edit, and publish blog posts (publishes BlogPostCreatedEvent, BlogPostPublishedEvent)
  • Comments - Add comments to blog posts (publishes CommentAddedEvent)

🔔 Event Subscribers

All actions trigger CAP events that are consumed by:

  • NotificationSubscriber
  • CacheInvalidationSubscriber
  • AnalyticsSubscriber
  • IntegrationSubscriber
  • AuditLogSubscriber

📚 How It Works

When you perform CRUD operations:

  1. API endpoint receives request
  2. Business logic executes
  3. CAP event is published
  4. RabbitMQ distributes to subscribers
  5. Subscribers process asynchronously
